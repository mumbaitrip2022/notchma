FAQ
Asked and answered.
Still curious? Ask on GitHub and a human answers.




Is it actually free?
Yes. Free, open source, MIT licensed. No account, no trial, no pro tier lurking in the shadows.


My Mac doesn't have a notch
NotchBar brings its own. On any Mac or external display, a little island floats at the top of the screen.


What does it work with?
Claude Code, Codex and Cursor, on Apple silicon Macs (M1 or newer) running macOS 14 Sonoma or later.


Will it slow my Mac down?
Nope. It's a 2 MB download, uses about 19 MB of memory and averages 0.3% CPU while your agents work. We measured it.


Does my code leave my Mac?
Never. NotchBar talks to your agents locally. It only goes online to check for updates and, after an agent pushes, to ask GitHub how CI is doing. That sends just the repo name and commit, and you can turn it off.


Does it show GitHub Actions?
Yep. When an agent pushes, the notch shows the commit's pipeline live, stage by stage, with the step that's running now. It taps you when it goes green or breaks, naming the job and step that failed. Public repos work with zero setup. For private repos, hit Connect GitHub in Settings once and sign in through your browser.


macOS won't open it. Help?
It's a one time thing. Open System Settings, go to Privacy & Security, and click Open Anyway. That's it, forever.
