Approvals

Say yes
without leaving flow.

When an agent wants to run something, the notch opens with the exact command or diff. Answer with a click, or with a shortcut from any app.

  • ⌃⌥Y allow, ⌃⌥N deny. Works from any app, even mid-sentence.
  • Risky commands stand out. Things like rm -rf or a force push turn red and never auto-approve.
  • Smart rules. Always allow a safe command in one project, or trust an agent for 10 minutes.
